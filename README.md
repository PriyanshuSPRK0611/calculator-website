# Calculator Website

A simple, elegant, and fully functional calculator built with HTML, CSS, and JavaScript.

## Features

✨ **Clean & Modern UI** - Beautiful gradient background with a sleek calculator design
🧮 **Full Calculator Operations** - Addition, subtraction, multiplication, and division
⌨️ **Keyboard Support** - Use your keyboard for quick calculations
🎯 **Error Handling** - Prevents division by zero and other errors
📱 **Responsive Design** - Works perfectly on desktop and mobile devices
🔄 **Clear & Delete** - Clear all or delete the last digit

## How to Use

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Start calculating!**

### Using the Calculator

- **Click buttons** to enter numbers and operators
- **Use keyboard** for faster input:
  - `0-9` for numbers
  - `+`, `-`, `*`, `/` for operations
  - `Enter` to calculate
  - `Backspace` to delete
  - `Escape` to clear

## Features Breakdown

### Buttons
- **Numbers (0-9)** - Input numerical values
- **Operations (+, -, *, /)** - Basic arithmetic operations
- **C** - Clear all and reset
- **←** - Delete the last digit
- **=** - Calculate the result
- **.** - Add decimal point

### Functionality
- Prevents multiple decimal points in a single number
- Prevents division by zero with an alert
- Keyboard support for all operations
- Smooth animations and hover effects
- Real-time display updates
